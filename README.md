# ml-research-notes

Daily theory notes from my traditional-ML roadmap (Nov 2026 →). One hour of reading a day, written down so it sticks.

- [`glossary.md`](glossary.md): every hard term, explained in plain English with a source
- [`reading-list.md`](reading-list.md): papers, books, and docs per topic, with status
- [`notes/`](notes/): one note per reading session (`YYYY-MM-DD-topic.md`)
- [`templates/note.md`](templates/note.md): the note format

Projects that use these notes live next to this repo in `ml-things/`.
